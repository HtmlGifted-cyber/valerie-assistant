# Getting started with Valerie

Valerie is a local AI assistant. The AI runs on this computer through Ollama, so chat stays on your machine; email, web search and "Ask Claude" only go out when you use them.

- Workspaces: separate areas (e.g. Work and Home, or two businesses). Each has its own mailbox, task board, memory, knowledge folders and time zone. Set them up in Settings > Workspaces. Nothing crosses between workspaces.
- Email: Valerie reads either from your mail server (add the password in Settings > Workspaces) or from Thunderbird's downloaded mail. Nothing is ever sent without your Yes.
- Voice: Voice button (read replies aloud), MIC (dictate into the box), Hold to Talk, and hands-free Talk mode ("Valerie, ..."). STOP or Esc stops anything; Pause holds everything.
- Skills: reusable instructions run as /name (Settings > Skills). Valerie can also create and edit them when you ask.
- Knowledge: add folders of your documents in Settings > Knowledge; Valerie answers from them.
- Schedule: reminders and check-ins, each in its own time zone (Settings > Schedule).
- Connectors: plug in task boards and web APIs (Settings > Connectors).
- Type /help for commands, or ask "what can you do?".
