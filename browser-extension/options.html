Valerie - Options

Connection

Keep this as http://127.0.0.1:8790 unless you changed Valerie's web port. This extension is only allowed to talk to http://127.0.0.1:8790.

Chrome only lets this extension reach http://127.0.0.1:8790. Other addresses will fail until the extension's manifest is changed.

Get it on the computer running Valerie: venv/bin/python app/valerie_web.py pair-extension (run from the Valerie folder). Stored only in this browser.

Privacy

  1. The extension reads a web page only when you click one of its buttons or a menu item.
  2. Page text is sent to your own Valerie on this computer. It is labeled as information only, never as instructions.
  3. Nothing is clicked, typed or filled in on web pages.
  4. It works only with your own Valerie. It does not send anything to a company or a cloud service of its own.
